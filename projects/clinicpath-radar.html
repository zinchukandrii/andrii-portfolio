CASE 02 / PUBLIC-SAFE NAVIGATION / LOCAL PRODUCT

Complex navigation with visible uncertainty.

ClinicPath Radar is a cinematic interface demonstrator for a public care-navigation journey. It separates system behavior, evidence, proof and safety into explicit routes instead of hiding boundaries behind a confident product surface.

ROLE
Product / design / implementation
STACK
React 19 · TypeScript · Vite · Three.js
ROUTES

DATA
Synthetic demonstration only
01 — JOURNEY

One narrative.
Six explicit boundaries.

The interface moves from system explanation to evidence, proof and safety before it reaches contact. Every journey item is labelled as a synthetic demo, and the product never presents itself as diagnosis, triage or medical advice.

03 — RECRUITMENT SIGNAL

Product craft joined to systems discipline.

The project demonstrates full-stack product judgment: information architecture, original visual language, route contracts, motion fallback, mobile behavior, browser checks and honest public boundaries. The presentation is cinematic; the acceptance criteria remain mechanical.

A demonstrator, not a care service.

ClinicPath Radar does not diagnose, triage, recommend a clinic or transmit a booking. It contains no patient information and makes no healthcare outcome claim. A production path would require validated data sources, clinical and legal review, consent, accessibility coverage, secure service integration and operational ownership.
