CASE 01 / MANUFACTURING INTELLIGENCE / WORKING MVP

Root cause without premature certainty.

An evidence-gated investigation system for ordered manufacturing data. It computes useful signals, manages DMAIC/8D work and produces an auditable report — while keeping association, alarms and generated hypotheses below the causal-confirmation boundary.

ROLE
System design / implementation
STACK
Python · FastAPI · SPC · SHA-256
DOMAIN
PVD / TiN demonstrator
DATA
24 published samples + 240 synthetic runs
01 — PROBLEM

A signal is not a cause.

A special-cause alarm, a high FMEA score or a parameter association can focus an investigation. None establishes causality. The system makes that distinction executable: the initial hypothesis remains TESTED and confirmation fails closed until independent evidence and accountable human review exist.

OBSERVE

Ordered evidence enters first.

CSV ingestion maps the CTQ, specification limits and baseline before SPC, capability or Pareto outputs are exposed.

INTERPRET

Analytics preserve their limits.

Associations are labelled non-causal; stability and MSA gates can block a capability claim even when indices remain visible.

CONFIRM

Evidence changes workflow state.

Three supporting records, independent sources, metrology or intervention, no unresolved contradiction, a completed plan and named approval are required.

02 — SYSTEM

Physical reference.
Synthetic incident.

The two data layers never collapse into one. Twenty-four experimental samples are transcribed from four open-access primary studies with DOI-level provenance and comparability limits. The 240-run incident fixture is deterministic and explicitly synthetic.

GATEHTTP 409

Premature confirmation remains blocked when evidence is incomplete.

TRACEHash chain

Evidence and workflow events receive an append-only SHA-256 trail.

CONTROLHuman approval

AI output can propose a hypothesis; it cannot bypass the same confirmation gate.

03 — DECISION FLOW

Problem → evidence → reviewable state.

01

Create the investigation.

Validate ordered data, CTQ mapping, limits and baseline.

02

Generate bounded signals.

I-MR, Pareto, Cp/Cpk/Pp/Ppk and non-causal association ranking.

03

Control the investigation.

DMAIC/8D checklist, owner, evidence note and append-only event.

04

Demand confirmation evidence.

Independent metrology or controlled intervention plus plan and human approval.

05

Export the record.

Downloadable Markdown report with analysis, checklist and audit hashes.

The boundary is part of the product.

This MVP stores investigations in process memory. It has no authentication, MES integration, persistent production database or generative AI model. Gage R&R is represented by a fail-closed MSA requirement rather than an ANOVA module. The audit chain is not an external immutable ledger. Production use requires durable storage, authenticated approvals, signatures, access control and equipment-specific validation.
